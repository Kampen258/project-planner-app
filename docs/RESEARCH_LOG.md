## 2026-07-06 — New Agile methodology refresh check

**Question:** Have the practices underlying our New Agile methodology
(USER_MANUAL.md v1.0, Oct 2025) changed materially?

**Method:** Web research across the methodology's source practices:
continuous discovery (Torres), product operating model (SVPG/Cagan),
State of Agile industry reports, flow metrics/Kanban, OKR practice, and
AI-in-discovery trends.

**Findings:**
1. Core methodology direction confirmed — outcome-over-output, continuous
   discovery, hybrid models (74% of teams), flow metrics all remain
   mainstream. Torres' framework stable (2026 book club, no revision).
2. Major delta: AI became a first-class methodology participant.
   84% AI adoption among agile practitioners (18th State of Agile,
   "fourth wave"); AI-moderated interviews baseline in 2026; AI synthesis
   cited by 88% of researchers as top trend; ~12x more customer
   conversations per PM with conversational AI. Synthetic users accepted
   for hypothesis generation only, never final validation.
   Caveat: individual gains (~70%) far outpace team-collaboration gains (~17%).
3. Metrics: DORA + SPACE now standard companions to flow metrics;
   dynamic WIP limits over fixed.
4. OKRs: 3-5 objectives/team/quarter; healthy score 0.6-0.7; "invisible
   OKR" abandonment named as governance anti-pattern; reference KRs in
   weekly planning.

**Decision:** Update USER_MANUAL.md to v1.1 (AI addendum + OKR scoring +
weekly KR reference + DORA/SPACE and dynamic-WIP notes). Add AI-assisted
discovery features to the backlog, reusing the app's existing Claude
services. No changes to the core two-track model.
